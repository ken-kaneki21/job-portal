# Job Intelligence Browser Companion

Chrome/Edge Manifest V3 companion for **user-assisted** job capture and Workday autofill.

- Captures the job page you are currently viewing (LinkedIn, Naukri, Foundit, Indeed, Workday, or a generic job page).
- Sends visible job content to your private Job Intelligence API for the same normalization/deduplication pipeline.
- Autofills common Workday fields from your saved candidate profile.
- **Never clicks final Submit.**
- Does not store or scrape job-board passwords.

Install: open `chrome://extensions` / `edge://extensions`, enable Developer mode, choose **Load unpacked**, and select this folder. Then save your API URL and generated companion token in the popup.
